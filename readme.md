## 介绍

一个简洁高效的 Webpack 插件，用于动态生成路由文件，帮助开发者轻松实现约定式路由功能。

---

## 特性

- 📦 **自动生成**：根据文件目录结构自动生成路由文件
- 🤝 **动态路由**：约定以`$`开头的文件为动态路由文件，例如 `$id.tsx`
- ⚙️ **多页面入口**：支持配置多个页面入口，默认以页面入口下的 `Layout.(jsx|tsx)` 作为局部路由，优先级高于全局路由；例如 `src/pages/Layout.tsx`
- 📝 **全局 Layout 支持**：默认使用 `src/layouts/index.(jsx|tsx)` 文件作为全局路由文件

---

## 安装

```bash
npm install webpack-plugin-auto-routes --save-dev
or
yarn add webpack-plugin-auto-routes --dev
or
pnpm add webpack-plugin-auto-routes --save-dev
```

## 使用方法

### 配置

在 `webpack` 或 `rspack` 中配置

```javascript
import WebpackPluginAutoRoutes from 'webpack-plugin-auto-routes';

export default {
  // ...其他配置项
  plugins: [new WebpackPluginAutoRoutes()],
};
```

在 `rsbuild.config.ts` 中配置

```javascript
import WebpackPluginAutoRoutes from 'webpack-plugin-auto-routes';

export default {
  // ...其他配置项
  tools: {
    rspack: {
      plugins: [new WebpackPluginAutoRoutes()],
    },
  },
};
```

### 使用

```javascript
import routes from 'virtual-routes';
```

引入 virtual-routes 会导出 routes 对象

```typescript
const routes = [...];

export default routes;
```

### 配置项

#### dirs

- **类型**: `string | (string | DirType)[]`
- **默认值**: `'src/pages'`

```typescript
type DirType = {
  /* 路径 */
  dir: string;
  /* 基本路径 */
  basePath?: string;
  /* 匹配规则 */
  pattern?: string | RegExp;
  /* 是否全局路由 */
  isGlobal?: boolean;
};
```

传入多个目录时，会递归遍历每个目录下的文件，生成对应的路由配置，并将基本路径加入生成的路由。

还可以使用 pattern 过滤文件，例如只生成以 `.tsx` 结尾的文件。

### 路由元数据

允许用户在文件中以注释的形式定义路由元数据，例如：

- `// route-id`: 路由 id，默认生成，例如 `src/pages/about` 会生成 `about` 作为 id
- `// route-parent-id`: 父级路由 id，如果存在页面局部路由或全局路由，会自动生成 parentId 为局部路由 id 或全局路由 id，为 null 时表示全局路由
- `// route-meta`: 其他自定义数据，例如 `// @route-meta: { "title": "/Page0.tsx" }`

### 示例

文件结构

```plaintext
src
├── layouts
│   └── index.tsx
├── pages
│   |—— sub1_0
│   |   |—— sub2_0
|   |   |   |—— Page2.tsx
│   |   |—— sub2_1
|   |   |   |—— Page3.tsx
|   |   |—— Page1.tsx
|   |—— Page0.tsx

```

生成的路由配置

```typescript
// @ts-nocheck
// this file is generated by webpack-plugin-auto-routes
// do not change anytime!
import React from 'react';

const routes = [
  {
    "id": "@@global-layout",
    "path": "/",
    "isLayout": true,
    "Component": React.lazy(() => import('../src/layouts/index.jsx')),
    "children": [
      {
        "id": "Page0",
        "path": "Page0",
        "parentId": "@@global-layout",
        "meta": {
          "title": "/Page0.tsx"
        },
        "Component": React.lazy(() => import('../src/pages/Page0.tsx'))
      },
      {
        "id": "sub1_0-Page1",
        "path": "sub1_0/Page1",
        "parentId": "@@global-layout",
        "meta": {
          "title": "/sub1_0/Page1.tsx"
        },
        "Component": React.lazy(() => import('../src/pages/sub1_0/Page1.tsx'))
      },
      {
        "id": "sub1_0-sub2_0-Page2",
        "path": "sub1_0/sub2_0/Page2",
        "parentId": "@@global-layout",
        "meta": {
          "title": "/sub1_0/sub2_0/Page2.tsx"
        },
        "Component": React.lazy(() => import('../src/pages/sub1_0/sub2_0/Page2.tsx'))
      },
      {
        "id": "sub1_0-sub2_1-Page3",
        "path": "sub1_0/sub2_1/Page3",
        "parentId": "@@global-layout",
        "meta": {
          "title": "/sub1_0/sub2_1/Page3.tsx"
        },
        "Component": React.lazy(() => import('../src/pages/sub1_0/sub2_1/Page3.tsx'))
      }
    ]
  }
];

export default routes;
```
